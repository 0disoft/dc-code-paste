dc-code-paste — 외부 AI 리뷰 안내

제품 목표
DCInside 글쓰기 화면에 붙여넣을 리치 텍스트 HTML을 만드는 정적 웹 도구다.
코드를 보기 좋게 보여주는 도구에서 출발했고, 일반 글도 편하게 쓰고 읽고 꾸며서
게시하는 도구로 확장했다. 작성 → 읽어보기/미리보기 → 복사 → 게시 흐름이 핵심이다.
현재 기능을 유지하는 것 자체보다 실제 사용에 도움이 되는 개선을 우선한다.

중요한 정보 구분
문서 목적, 생각 조각 보관함의 비공개 내용, 읽기 메모, 문장 관계와 관계 이름은
초안에 보관하는 작업 정보다. 공개 HTML, 일반 텍스트 복사 등 공개 출력에
흘러나오지 않아야 한다. 본문에 실제로 넣은 조각의 글·코드는 본문으로 공개된다.
문장에 연결한 공개 출처 링크와 참고 자료는 의도적으로 공개하는 정보다.
readingIntent 같은 읽기 배치 정보는 위 비공개 메모와 구분해 실제 코드를 살펴본다.
파일 이름이나 현재 코드만으로 보장되었다고 단정하지 말고 출력 경로별로 추적한다.

검증 경계
이번 자료 준비 작업은 압축 구성과 원본 일치 여부를 확인하는 작업이다.
이 작업에서 앱 테스트나 빌드를 새로 실행했다는 뜻은 아니다.
테스트 코드와 CI 설정이 존재하는 것과 실제로 통과한 것은 구분한다.
실제 DCInside 서비스에 붙여넣은 결과와 실제 OS 클립보드 호환성은 미확인이다.
정적 분석만으로 발견한 것은 위험 후보로, 직접 실행한 것만 재현 결과로 보고한다.
UX 평가는 코드에서 추론한 내용과 화면을 직접 조작해 확인한 내용을 구분한다.

실행 참고 (저장소 스크립트)
bun install --frozen-lockfile
bun run dev
bun run check
bun run typecheck:go
bun run lint
bun run format:check
bun run test --run
bun run test:e2e
GitHub Pages 빌드: BASE_PATH=/dc-code-paste bun run build
마지막 줄의 환경 변수 문법은 POSIX 셸 기준이다. PowerShell에서는
$env:BASE_PATH = '/dc-code-paste' 설정 후 bun run build를 실행한다.
실행 환경이 없다면 실행 불가를 밝히고 정적 검토를 진행한다.
