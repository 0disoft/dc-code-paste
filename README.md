# dc-code-paste

DCInside 글쓰기 화면에 붙여넣을 리치 텍스트 HTML을 만드는 정적 웹 도구.

**→ https://0disoft.github.io/dc-code-paste/**

---

## 주요 기능

- 글쓰기 에디터 + 실시간 미리보기
- 집중해서 쓰기 (더보기 메뉴에서 좌우 패널을 접고, 필요한 도구만 잠깐 열기 · 원문 선택과 읽던 위치 유지)
- 이 글의 목적 (더보기 메뉴에서 선택적으로 한 문장 보관 · 편집·읽어보기에서 펼쳐 확인 · 초안에는 남고 복사 결과에는 포함되지 않음)
- 생각 조각 (정리 전 문장·코드·주소를 초안에 보관 · 선택한 글자 가까이에서 원문을 유지하며 바로 보관 · PC에서 본문 곁에 두고 계속 편집 · 보관한 내용과 넣은 구간 검색 · 아직 넣지 않은 조각과 다시 확인할 조각만 보기 · 검색·화면 전환 중에도 수정 중인 입력 유지 · 글 또는 코드로 본문에 넣기 · 새로 넣은 구간의 수정·삭제·복제 확인 · 보관함에서 지워도 본문은 유지)
- 처음부터 읽어보기 (구간을 차례로 펼치고 멈춘 이유를 초안에 메모 · 원문으로 이동하면 메모를 곁에 두고 수정 · 당시 원문과 변경된 구간 비교 · 메모는 복사 결과에 포함되지 않음)
- 읽는 구간의 생각 조각 확인 (현재 구간에 넣었던 내용만 확인 · 달라진 원문은 글을 전부 펼친 뒤 보기 · 보관한 조각의 비공개 수정 내용은 표시하지 않음 · 해당 본문으로 이동)
- 여기까지 나온 연결 (차례로 읽는 동안 연결된 근거·조건·반론이 나왔는지 확인 · 아직 펼치지 않은 문장은 숨기고 구간 거리만 표시 · 원하는 연결 구간까지 펼치거나 앞 구간 다시 보기)
- 선택한 글자 가까이에서 굵게·기울임·출처 연결 (읽는 의도는 필요할 때 펼치기 · 선택과 실행 취소 유지)
- 읽는 의도 표시 + 같은 원문의 두 읽기 배치 비교 (줄 간격·문단 여백을 선택하고 편집·복사·초안 복원에 함께 적용)
- 읽기 경로 점검 (글 구성에서 먼저 읽을 문장·근거·질문 등 표시한 구간만 원문 순서대로 읽고 해당 위치로 이동)
- 강조 점검 (미리보기에서 굵게·먼저 읽기 구간만 모아보기 · 제목과 코드 제외 · 겹친 강조를 한 번만 계산하고 원문으로 이동)
- 문장 관계 연결 (근거·조건·반론 또는 직접 붙인 관계 이름으로 두 구간 연결 · 이동 후에도 원문 찾기 · 수정·삭제·복제로 다시 확인할 구간 표시 · 관계와 이름은 초안에 보관)
- 연결 구간 나란히 보기 (멀리 떨어진 두 구간을 편집기 위에서 함께 읽기 · 원문 수정 즉시 반영 · 삭제·복제된 구간은 연결 당시 원문으로 확인)
- 문장 출처 연결 (자료 주소·이름·근거 원문을 문장에 보관하고, 복사할 때 문장 뒤에 출처 링크 표시)
- 출처 재사용·모아보기 (문장 출처와 참고 자료 목록을 주소별로 모으고 연결 문장으로 이동)
- 출처 연결 구간 재확인 (연결·기준 갱신 이후 문장 변경을 표시하고, 확인할 구간만 모아보기)
- 새 글 기본값 기억 (배치·배경·본문 글꼴·크기를 다음 새 글과 템플릿에 적용하고, 불러온 글의 설정은 보존)
- 마지막 복사 결과 보관 (현재 글과 비교·같은 결과 재복사·HTML 파일 저장·당시 글 복원, 더보기 메뉴에서 열기)
- 붙여넣기 왕복 비교 (디씨 편집기에서 다시 복사한 글을 마지막 복사 결과와 비교 · 텍스트·링크·목록·서식 정보 변화 확인 · 선택한 구간만 다시 복사해 부분 복구)
- 코드블록 (파일명, 언어, 라인 하이라이트, 추가/삭제/강조 줄 표시)
- 콜아웃, 요약, 튜토리얼, 비교, references, CTA 블록
- Markdown 가져오기 및 적용
- **AI 글 작성** — API 키와 모델을 설정하면 요청 한 번으로 Markdown 초안을 생성하고 에디터에 바로 적용
- LLM 가이드 복사 (외부 LLM 연동용)
- 프리셋 저장 (30개 한도에서 새 저장을 안내하고 기존 보관본 유지)
- 초안 히스토리 (수동 보관본 30개와 최근 자동 복구 기록 10개를 구분 · 이름 붙인 기록과 예전 기록은 보관본으로 유지)
- 라이트/다크 테마
- 브라우저 종료 후에도 localStorage로 자동 복원 (미적용 Markdown·AI 원고도 초안 기록·파일과 함께 보관)

## 기본 사용 흐름

1. 왼쪽 편집기에서 글을 작성한다.
2. 오른쪽 미리보기에서 결과를 확인한다.
3. `디씨 복사` 버튼을 클릭한다.
4. DCInside 글쓰기 에디터에 붙여넣는다.

> **주의:** 이 도구는 DCInside 에디터에 **리치 텍스트로 붙여넣는** 도구다.
> HTML 원문을 DCInside HTML 모드에 직접 입력하는 방식과 다르다.
> 미리보기 패널을 `HTML`로 전환하면 `원문 복사`로 raw HTML 소스도 복사할 수 있지만,
> 일반적인 사용은 `디씨 복사` → 에디터 붙여넣기다.

## AI로 글 작성하기

상단 툴바의 `AI` 버튼을 클릭하면 AI 작성 패널이 열린다.

1. **제공자**를 선택한다.
2. **모델**을 입력하거나 자동완성 목록에서 선택한다.
3. **API 키**를 입력한다. 키는 브라우저에 저장되지 않는다.
4. **요청**에 원하는 글 주제나 지시를 입력한다.
5. `생성하기`를 클릭하면 LLM이 Markdown을 생성하고, 완료되면 Markdown 패널에 자동으로 넣어준다.
6. Markdown 패널에서 `적용하기`를 클릭하면 에디터에 반영된다.

## LLM 가이드 복사로 외부 LLM 연동하기

앱 내 AI 기능 대신 ChatGPT, Claude, Gemini 웹 등 외부 LLM을 직접 사용하려면:

1. `가이드` 버튼을 클릭해 작성 규칙을 복사한다.
2. 원하는 LLM에 규칙과 작성할 주제를 함께 전달한다.
3. LLM이 출력한 Markdown을 복사한다.
4. dc-code-paste에서 `MD` 버튼을 클릭한다.
5. 입력창에 Markdown을 붙여넣고 `적용하기`를 클릭한다.
6. 편집기와 미리보기에 변환된 글이 표시된다.
7. 내용을 확인하거나 편집한 뒤 `디씨 복사`로 DCInside에 붙여넣는다.

`:::hero`, `:::summary`, `:::tip`, `:::warning` 같은 블록 태그와 코드블록은
반드시 `MD` 패널을 통해 적용해야 한다.
LLM 결과를 편집기에 직접 붙여넣는 방식으로는 블록 태그가 해석되지 않는다.

## DCInside 붙여넣기 주의사항

Playwright CI는 Chromium, Firefox, WebKit에서 편집·복사 흐름을 검사한다. 실제 OS 클립보드와 DCInside 에디터의 붙여넣기 결과는 별도로 확인해야 한다. 자동 복사가 거절되면 화면에 표시된 HTML 원문을 복사해 DCInside **HTML 모드**에 붙여넣는다. 일반 에디터에 HTML 원문을 붙여넣으면 서식이 적용되지 않는다.

릴리스 전 아래 항목을 브라우저에서 직접 확인한다.

1. 기본 샘플 아티클(단락, 제목, 팁박스, 경고박스, 참조박스, 링크박스, 인용, 목록, 구분선, 코드블록 포함)로 시작한다.
2. `디씨 복사` → DCInside 일반 에디터에 붙여넣기 → 스타일 유지 확인.
3. 미리보기 패널을 `HTML`로 전환 → `원문 복사` → DCInside HTML 모드에 붙여넣기 → HTML 모드 해제 후 동일하게 렌더링되는지 확인.
4. 코드 색상, 박스 여백, 링크, 본문 폰트 크기가 미리보기와 충분히 일치하는지 확인.
5. 텍스트 편집 후 새로고침 → 초안이 복원되는지 확인.
6. `초기화` → 새로고침 → 빈 아티클이 오는지 확인.
7. `DC 테이블` 모드에서 내보낸 HTML에 `table`, `td`, `bgcolor` 속성이 있는지 확인.
